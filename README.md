# 🎓 Agentic AI Teaching Assistant

A goal-driven AI agent that helps online students by reading their emails, checking course records, and drafting professional replies—demonstrating core principles of **agentic AI**.

Built with **LLM + tool augmentation** in Google Colab.

## 🚀 Features
- Understands natural language student queries (e.g., _“When is A2 due?”_)
- Checks mock student records (simulating an LMS like Canvas)
- Follows course policies to avoid hallucinations
- Drafts ready-to-send email replies using **Google Gemini**
- Handles missing info, emotional tone, and edge cases

## ▶️ How to Run
1. Open the notebook in [Google Colab](https://colab.research.google.com/)
2. Run all cells (no API key needed if signed into Google)
3. See the agent respond to sample student emails!

> 💡 **Note**: The student database is simulated (as is standard in agentic AI demos). In production, this would connect to a real LMS via API.

## 🧠 Why This Is Agentic AI
This project demonstrates:
- **Perception**: Reads unstructured student emails  
- **Reasoning**: Uses verified data + policies  
- **Action**: Generates accurate, empathetic replies  
- **Tool Use**: Queries internal "database"  
- **Human-in-the-loop**: Designed for review before sending  

Built for education, reliability, and clarity.
